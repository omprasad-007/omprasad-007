# Snake — Responsive HTML Game

Open `index.html` in a browser (double-click or serve via a simple static server).

Quick start (from repository root):

```bash
# open in default browser (Linux/macOS)
xdg-open snake/index.html

# or serve locally with Python (works in devcontainers)
python3 -m http.server 8000 --directory snake
# then open http://localhost:8000
```

Controls
- Arrow keys or WASD to move
- Space to pause/resume
- R to restart
- Swipe on touch devices
- Speed slider and Walls toggle available in UI

The game is self-contained and responsive.
